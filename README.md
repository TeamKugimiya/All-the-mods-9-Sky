模組包 All the Mods 9 - To the Sky 中文化補丁，模組包譯名：ATM9 翱翔天際。

## **簡介**

本中文化補丁涵蓋了模組包大多數內容，如：FTB Quests 任務、KubeJS 自訂物品、思索情境教學。<br>
為獲得完整的中文化體驗，請安裝下列資源包：

* [模組翻譯包][ModsTranslationPack]：由翻譯組製作的模組翻譯集大成。
* [Para 翻譯包][ParaTranslationPack]：由 [ParaTranz] 社群貢獻的模組翻譯。

請安裝下列模組：

* [Resource Pack Overrides][RO]：使內建資源包的標題、敘述可被翻譯。
* [Vault Patcher][vaultpatcher]：使模組的部分硬編碼文本可被翻譯。

## **安裝補丁**

詳細的圖文安裝教學，請前往我們 [官網][website] 查看。
